# Methodology Notes

1. Download APR, SLY4, and DD2 EOS tables from CompOSE.
2. Build the compactness-threshold scan.
3. Reconstruct thermo--TOV mass--radius sequences from `eos.nb` and `eos.thermo`.
4. Validate reconstructed sequences against official CompOSE `eos.mr` curves.
5. Generate paper figures and CSV outputs.

Scope: zero-temperature equilibrium thermo--TOV reconstruction; approximate compactness-based tidal deformability; no radial-mode stability, rotation, merger dynamics, or full Love-number integration.
